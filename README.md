## Step 1 - Design

I initially made some simple Figma Designs. I'm not a designer so they aren't perfect, but they're enough to start coding from.
After having some difficulty making my previous portfolio site mobile-responsive, I decided to take a mobile-first approach to the design.

## Step 2 - Development

Since this is a simple portfolio, I wont be needing much of a back-end for this. I'm hosting this with hostgator, so my domain and hosting is done for me. I just need to use an ftp to upload the site.
The important part is the front-end. I made this using _React, TypeScript and Vite_.
To keep things clean, I also opted to use the _Styled Components_ library instead of classes.
